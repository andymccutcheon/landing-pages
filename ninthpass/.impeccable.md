# Ninth Pass design context

Ninth Pass is an open-source command-line prompt-review tool for terminal-capable agent builders. The page's job is to explain the process, show an unchanged captured run, and route visitors to the working GitHub setup path. It must not imply demonstrated answer-quality improvements, verified semantic edits, independent model vendors, or human certification.

## System reality

Standalone static HTML, CSS and JavaScript. No shared Pattern imports, framework or runtime dependency. Semantic tokens live in `css/pz-tokens.css`; all three diagram documents consume the same tokens and diagram stylesheet/script. Self-hosted Fraunces and Geist; Geist Mono is restricted to actual code. Real artifacts in `examples/runs/meeting-notes/` are immutable source material.

## Design context

Direction: The Review Room. Smoked near-black, mineral-white type and citron signals. Oversized, tightly set sans-serif statements; full-face serif editorial passages provide rhythm, never an italic accent word. The real 8 → 8 → 9 trajectory becomes the signature visual. Three diagrams explain time, feedback and process boundaries separately. No generic neural imagery, invented performance statistics, logo wall or equal feature-card grid.

Autonomous loops are the default. A persistent page-level “Pause motion” setting stops all motion and automatic diagram progression, satisfying the stop mechanism for moving content without diagram playback chrome. Operating-system reduced motion wins over stored preferences. Static compositions preserve all information. Offscreen documents and hidden tabs suspend clocks.
