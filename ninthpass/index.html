Separate the process.
Keep the evidence.

The built-in OpenCode, Claude Code and Codex workers start a new process for each stage. Silverquill forwards the stage packet rather than the conversation that produced the draft.

Separate processes can use the same model and provider. In manual mode, your host must provide fresh contexts. Process separation is not a security sandbox.

A score.
Not a certificate.

Know what a 9 means—and what it doesn’t.

Read the published rubric ↗

Two scores from one run: the composed agent, then the approved agent. The gate is the score, not a count of passes.

Published scoring bands, summarized
ScoreRubric summary
0–3Missing, contradictory or unsafe
4–6Present but thin
7–8Usable, with gaps
9–10Stop-loop caliber

Judge is instructed to cite prompt text or structural facts. An overall score of at least 9 means STOP under this rubric. A lower score means CONTINUE.

The model judges the prompt. The code checks return formats, score/verdict agreement and recommendation accounting. It does not establish that cited evidence is sound or that a claimed edit was made.

This run’s final prompt still has limitations. These artifacts do not demonstrate its performance on a meeting transcript. STOP requires no human sign-off and does not certify that an agent’s answer will be right.

  --request "An agent that summarises meeting notes into five short, useful bullets" \

Already have a prompt?

node dist/cli.js run --prompt ./prompt.md --worker claude

Three capabilities. One loop.

Create, evaluate and refine. Each skill installs into your agent and can be used on its own; the loop runs them in order.

Compose
CreateTurns what you want an agent to accomplish into a System Prompt and a Task Prompt. It never performs the task.
Judge
EvaluateScores those instructions against the published rubric, quotes the lines that are weak, and numbers its recommendations.
Revise
RefineApplies the numbered recommendations and returns a checklist of what was applied or deferred.
Loop
OrchestrateRuns the three stages in order and keeps the record. Also available as one command: node dist/cli.js run --request "…"
Brief
One-off taskA separate path: turns a rough task assignment into a single execution-ready brief, without building an agent. A task-like input given to Compose still produces System and Task Prompts.
