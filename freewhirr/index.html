Free-first model router · independent project

Spend nothing until you choose to.

freewhirr tries OpenRouter's $0 models in order and fails over when one rate-limits, errors or times out. Free models are not guaranteed to answer. When they all fail, you get an error unless you have opted in to paid fallback.

$ pip install freewhirr
Quickstart

How a request is routed

Models come from your own pinned list, from OpenRouter's catalog where the price is zero, or both.

Rate limit
A rate limit is retried on the same model with backoff.
Error
A context-length error or most other client errors move straight to the next model.
Timeout
A timeout is retried before moving to the next model.
Context window
A context-length error or most other client errors move straight to the next model.

Streaming can only fail over before the first token. After that, an error is passed to the caller, because switching models mid-answer would corrupt the stream.

Free models are generous. They are also flaky.

The common workaround

The common workaround is to hard-code one cheap paid model, and then pay for work a free model would have done.

rate-limit

freewhirr reverses that default.

It walks the free list first and moves on when a model fails. Paid models stay out of the path until you put them in it.

exhaustion_policy: stop

Set the caps before you switch to paid. Every cap is off until you set it. With paid and no caps, the only limit is the list of models.

Two settings that change what "free" means. A model you pin in free_models is treated as free whatever it costs, and so is a model a client asks for when honor_requested_model is on. Both are off or empty by default. Pin only $0 models.

Quickstart

You need Python 3.10 or newer and an OpenRouter API key.

Install

python -m pip install freewhirr
export OPENROUTER_API_KEY=sk-or-v1-...

From Python

from freewhirr import Freewhirr

with Freewhirr() as client:
    result = client.complete(
        messages=[{"role": "user", "content": "Explain vector clocks in one paragraph."}]
    )
    print(result.model)
    print(result.content)

From the command line

freewhirr chat "Explain vector clocks in one paragraph."

Each result

.model
which model answered
.content
the answer
.cost_usd
the cost
.paid
whether the call was paid
.models_tried
which were tried

A library, a proxy, or a command line

Python library.

Sync and async clients, plus a namespace shaped like the OpenAI SDK's. Each result tells you which model answered, which were tried, and whether the call was paid.

result = client.complete(messages=[...], quality=MinLengthCheck(40))
async_result = await client.acomplete(messages=[...])
for chunk in client.stream(messages=[...]):
    print(chunk["choices"][0]["delta"].get("content") or "", end="")
client.chat.completions.create(messages=[...])

Library surface

Local proxy.

One process that accepts OpenAI Chat Completions, the OpenAI Responses API and Anthropic Messages, with streaming on all three. Point a client's base URL at it.

By default the proxy ignores the model name the client sends, so an app with a paid model hard-coded cannot skip the free list.

freewhirr serve --port 8787

Then point an OpenAI-compatible client at http://127.0.0.1:8787/v1. With no configuration file the policy is stop.

# examples/proxy_openai.py
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8787/v1", api_key="not-used")
response = client.chat.completions.create(
    model="freewhirr",
    messages=[{"role": "user", "content": "Give me a one-line haiku about buses."}],
)
print(response.choices[0].message.content)

Setup notes in the README

The proxy has no login. It listens on 127.0.0.1 by default and does not check the key a client sends. Anyone who can reach the port can spend against your OpenRouter key under your policy. Keep it on localhost, or put your own authentication in front of it before you expose it.

Command line.

freewhirr chat for a one-off prompt, freewhirr models to see the list the next call would walk, freewhirr stats for the ledger, freewhirr config to print resolved settings with the key hidden.

chat
Send a one-shot chat completion.
serve
Run an OpenAI-compatible proxy.
stats
Show free vs paid share and estimated savings.
models
List the free models the router would try.
watch
Poll OpenRouter for new and stealth free models.
config
Print the resolved configuration (secrets redacted).

Settings: yours, in any format

Configuration comes from a YAML or TOML file, environment variables, or arguments in code, in that order of precedence.

  1. defaults
  2. a YAML or TOML file
  3. environment variables
  4. constructor arguments: later wins
# YAML
exhaustion_policy: stop

# TOML
exhaustion_policy = "stop"

# Environment variable
FREEWHIRR_EXHAUSTION_POLICY=stop

# Python
FreewhirrConfig(exhaustion_policy=ExhaustionPolicy.STOP)

The one required setting is your OpenRouter key.

The cost of free

The project's README warns that most free endpoints may train on prompts. freewhirr sends your prompt to OpenRouter and to whichever model provider answers.

Set deny_data_collection: true and freewhirr asks OpenRouter to route only to providers that do not collect prompts.

deny_data_collection: true

That shrinks the free list, sometimes to nothing, and then stop fails closed.

Request logs and spend totals are written to a file on your machine. freewhirr has no telemetry of its own.

Each request carries an app name and a link identifying freewhirr. You can change both.

The savings figure is an estimate for your own bookkeeping. It is not an invoice, and it is not a prediction of what you will save.
