01 / PROMPT CONTROLBUILT FOR YOUR MCP CLIENT

THE WORKFLOW

A prompt gets a process.

Each stage has one job. The controller keeps the run moving, records the work, and stops when the Judge says the prompt is ready.

01

Metapod

Shapes a raw request into a System Prompt and a Task Prompt. It prepares the work; it never performs it.

GENERATE
02

Judge Dredd

Scores a system prompt against a locked rubric, quotes evidence, then returns a verdict and numbered recommendations.

EVALUATE
03

Brian Spillner

Rewrites against every recommendation, then returns the full prompt with a checklist of what it applied.

REFINE
↳

STOP when overall is 9 or higher

Continue through at most four scoring rounds. At the cap, a run is provisional; after two rewrites without improvement, it pauses for your decision.

LOCAL FIRST · STDIO

Add it to your client.

Promptzilla is an MCP server. Install it from npm, then let your client connect.

CLAUDE CODENODE.JS 22.12+
claude mcp add promptzilla -- npx -y promptzilla

Your MCP client must be configured and running. The AI client runs the skill instructions.

Using Claude Desktop, Cursor, or another MCP client?

Merge this entry into your MCP client configuration:

{
  "mcpServers": {
    "promptzilla": {
      "command": "npx",
      "args": ["-y", "promptzilla"]
    }
  }
}
